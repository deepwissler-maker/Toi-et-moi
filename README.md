# Toi & Moi ♥

Un petit univers numérique personnel, créé pour raconter notre histoire.
Site statique, sans framework, hébergé sur GitHub Pages.

---

## Concept

Une expérience interactive et émotionnelle : un ciel étoilé, des souvenirs,
des lettres, des feux d'artifice, et quelques surprises cachées.

---

## Fonctionnalités prévues

- Hero immersif avec ciel étoilé
- Feux d'artifice romantiques
- Timeline "Notre histoire"
- Lettres personnelles (enveloppes à ouvrir)
- Compteur de temps depuis une date clé
- Musique de fond (optionnelle, désactivée par défaut)
- Surprises et easter eggs
